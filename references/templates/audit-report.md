## Инструкция по использованию шаблона

### Как заполнять:

1. **Общая информация** -- собрать данные о компании, юрисдикциях, целевой аудитории.
2. **Провести аудит** -- проверить сайт по каждой применимой юрисдикции:
   - Россия: 152-ФЗ, ЗоЗПП, 54-ФЗ (онлайн-кассы), ГК РФ (оферта).
   - ЕС: GDPR, ePrivacy, DSA, EAA.
   - UK: UK GDPR, PECR, DPA 2018.
   - США: CCPA/CPRA.
   - ОАЭ: PDPL, DIFC/ADGM (если применимо).
3. **Классифицировать находки** по уровню критичности:
   - 🔴 **Критичные**: прямое нарушение закона, реальный риск штрафа/блокировки.
   - 🟡 **Важные**: несоответствие требованиям, повышенный риск, но не немедленная угроза.
   - 🟢 **Рекомендации**: best practice, которые усилят защиту.
   - ✅ **В порядке**: то, что уже соответствует требованиям.
4. **Приоритизировать исправления** -- от самых рискованных к менее срочным.
5. **Составить карту документов** -- какие юридические документы нужны и в каком состоянии.

### Типичные критичные нарушения для SaaS:

- Отсутствие Политики конфиденциальности (152-ФЗ, GDPR).
- Нет механизма получения согласия на обработку ПД (152-ФЗ).
- Нет cookie-баннера для EU-пользователей (ePrivacy).
- Нет ссылки "Do Not Sell or Share" для CA-пользователей (CCPA).
- Хранение ПД россиян за пределами РФ без локальной базы (152-ФЗ ст. 18).
- Отсутствие DPA для B2B-клиентов из ЕС (GDPR Art. 28).
- Нет уведомления Роскомнадзора об обработке ПД (152-ФЗ ст. 22).
- Отсутствие публичной оферты (ГК РФ ст. 435-437).

### Типичные важные замечания:

- Неполная Политика конфиденциальности (нет всех обязательных разделов).
- Нет информации о сроках хранения данных.
- Нет процедуры обработки запросов субъектов данных.
- Cookie-баннер с pre-ticked boxes или без кнопки "Отклонить".
- Нет уведомления о субпроцессорах.
- Оферта/ToS не покрывает ответственность и ограничения.

### Типичные рекомендации:

- Добавить self-service экспорт данных (GDPR portability).
- Внедрить автоматическое удаление данных по истечении срока хранения.
- Получить ISO 27001 / SOC 2 сертификацию.
- Провести DPIA для новых функций с высоким риском.
- Улучшить доступность сайта до WCAG 2.1 AA.
- Добавить мультиязычность юридических документов.
