# Кэш первоисточников

В этой папке локально хранятся документы, используемые для исследования и проверки. Кэш исключён из системы контроля версий, потому что сторонние документы могут иметь отдельные условия авторского права, распространения или доступа.

Когда для задачи нужен актуальный первоисточник, получите его у первоначального издателя и зафиксируйте в отчёте или исследовательской заметке ссылку на источник и дату обращения.
