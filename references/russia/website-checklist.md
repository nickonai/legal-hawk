## C. Формы сбора данных

- [ ] **C1.** Каждая форма содержит ссылку на Политику обработки ПД
- [ ] **C2.** Каждая форма содержит чекбокс согласия на обработку ПД (не pre-checked)
- [ ] **C3.** Форма не отправляется без проставления чекбокса согласия
- [ ] **C4.** Отдельный чекбокс для маркетинговых рассылок (не pre-checked, с 01.09.2025)
- [ ] **C5.** Собираются только необходимые данные (принцип минимизации -- ст. 5 152-ФЗ)
- [ ] **C6.** Цель сбора данных обозначена рядом с формой или в согласии
- [ ] **C7.** Регистрационная форма: не запрашивает избыточные данные
- [ ] **C8.** Контактная форма: согласие на обработку ПД
- [ ] **C9.** Форма обратного звонка: согласие + цель "для осуществления обратного звонка"
- [ ] **C10.** Форма подписки на рассылку: отдельное маркетинговое согласие
- [ ] **C11.** Форма оплаты: ссылка на оферту + подтверждение акцепта

## D. Cookie и трекинг

- [ ] **D1.** Cookie-баннер отображается при первом визите
- [ ] **D2.** Баннер содержит информацию о типах cookie
- [ ] **D3.** Есть возможность принять/отклонить необязательные cookie
- [ ] **D4.** Кнопка "Отклонить" / "Только необходимые" -- равноценна по размеру кнопке "Принять"
- [ ] **D5.** Аналитические cookie и другие средства веб-аналитики НЕ загружаются до согласия
- [ ] **D6.** Маркетинговые cookie (рекламные пиксели соцсетей, ретаргетинг) НЕ загружаются до согласия
- [ ] **D7.** Строго необходимые cookie работают без согласия (сессия, CSRF)
- [ ] **D8.** Есть страница / раздел с полным описанием cookie (реестр cookie)
- [ ] **D9.** Пользователь может изменить настройки cookie в любой момент (ссылка в footer)
- [ ] **D10.** Cookie-настройки сохраняются (не запрашиваются повторно при каждом визите)
- [ ] **D11.** Политика cookie описана в Политике обработки ПД или отдельном документе

- [ ] **E1.** Цены указаны в рублях -- ст. 10 ЗоЗПП, ст. 317 ГК РФ
- [ ] **E2.** Итоговая стоимость видна перед оплатой (без скрытых комиссий)
- [ ] **E3.** Настроена онлайн-касса (ККТ) для B2C платежей -- 54-ФЗ
- [ ] **E4.** Электронные чеки отправляются покупателям (email/SMS) -- ст. 1.2 54-ФЗ
- [ ] **E5.** В чеке указано наименование услуги/тарифа -- ст. 4.7 54-ФЗ
- [ ] **E6.** В чеке указана правильная ставка НДС (20% / без НДС / 5% / 7%)
- [ ] **E7.** При автопродлении: уведомление за 3 дня до списания -- ст. 26.2 ЗоЗПП

- [ ] **E9.** При возврате формируется чек "возврат прихода" -- 54-ФЗ
- [ ] **E10.** Страница оплаты содержит ссылку на оферту и подтверждение акцепта
- [ ] **E11.** Есть кнопка / механизм отмены подписки в личном кабинете -- ст. 32 ЗоЗПП
- [ ] **E12.** Процедура возврата описана в оферте и на сайте

## G. Техническое обеспечение

### Хостинг и локализация данных

- [ ] **G1.** Персональные данные граждан РФ хранятся на серверах в РФ -- ч. 5 ст. 18 152-ФЗ
- [ ] **G2.** Есть документальное подтверждение локализации (договор с хостинг-провайдером)
- [ ] **G3.** Резервные копии с ПД -- на серверах в РФ
- [ ] **G4.** CDN не кеширует ПД за пределами РФ (или использует российские узлы)

### Шифрование и безопасность

- [ ] **G5.** TLS 1.2+ для всех страниц (HTTPS) -- обязательно при передаче ПД
- [ ] **G6.** SSL-сертификат действителен и корректно настроен
- [ ] **G7.** HTTP автоматически перенаправляет на HTTPS
- [ ] **G8.** Пароли хранятся в хешированном виде (bcrypt, Argon2)
- [ ] **G9.** Двухфакторная аутентификация для администраторов -- ФСТЭК Приказ N 21
- [ ] **G10.** Разграничение доступа к ПД (RBAC) -- ФСТЭК Приказ N 21
- [ ] **G11.** Логирование доступа к ПД -- ФСТЭК Приказ N 21

### Аналитика и сторонние сервисы

- [ ] **G12.** Google Analytics: IP-анонимизация включена (или отключена до согласия)
- [ ] **G13.** Инструмент веб-аналитики с записью поведения пользователя -- уведомление пользователей
- [ ] **G14.** Сторонние скрипты не загружаются до cookie-согласия (аналитика, маркетинг)
- [ ] **G15.** Каждый сторонний сервис, получающий ПД, указан в Политике обработки ПД
- [ ] **G16.** С каждым обработчиком ПД (процессором) заключено поручение на обработку -- ч. 3 ст. 6 152-ФЗ
- [ ] **G17.** При трансграничной передаче: уведомление Роскомнадзора подано -- ст. 12 152-ФЗ

### Приоритеты устранения

**КРИТИЧЕСКИЙ** (устранить немедленно -- штрафы/блокировка):
- Отсутствие Политики обработки ПД (штраф 60 000-100 000 руб.)
- Нелокализация данных (штраф 1-6 млн руб.)
- Неуведомление Роскомнадзора (штраф 100 000-300 000 руб.)
- Неприменение ККТ (штраф от 30 000 руб. или 75-100% суммы расчётов)
- Образовательная деятельность без лицензии (штраф 170 000-250 000 руб.)

**ВЫСОКИЙ** (устранить в течение 1 месяца):
- Отсутствие отдельного согласия на маркетинг (с 01.09.2025)
- Cookie без согласия
- Ущемляющие условия в оферте
- Отсутствие модели угроз

**СРЕДНИЙ** (устранить в течение 3 месяцев):
- Неполная информация о компании
- Неполная Политика ПД
- Отсутствие cookie-баннера
- Не все формы содержат чекбокс согласия

**НИЗКИЙ** (рекомендательные):
- Отсутствие архива версий документов
- Отсутствие КПП на сайте
- Отсутствие телефона
