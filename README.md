# Душный юрист

«Душный юрист» — доказательный навык для юридического аудита SaaS-продуктов и онлайн-образования. Его технический идентификатор — `legal-hawk`, а публичное русское название — «Душный юрист».

Навык ищет пробелы в соблюдении требований, приводит доказательства из проверяемого продукта, отделяет подтверждённые выводы от допущений и завершает ответ конкретными действиями. Он охватывает Россию, ОАЭ, ЕС, Великобританию и США: персональные данные, права потребителей, подписки, рекламу, доступность, раскрытие применения ИИ и интеллектуальную собственность в пользовательском и сгенерированном ИИ контенте.

## Важное предупреждение

Этот репозиторий и скилл созданы исключительно в учебных и информационных целях. Они не являются юридической консультацией и не заменяют квалифицированного юриста.

Материалы основаны на общедоступной документации и источниках из интернета. Они могут быть неполными, неточными или устаревшими: законодательство, судебная практика и официальные разъяснения меняются. Не принимайте юридические, финансовые или иные значимые решения только на основе материалов репозитория. Сначала проверьте актуальные первоисточники и обратитесь к юристу по соответствующей юрисдикции.

## Установка

Клонируйте репозиторий и подключите его как каталог навыков Codex или Claude:

```sh
ln -s /абсолютный/путь/к/legal-hawk ~/.codex/skills/legal-hawk
```

Точка входа — [SKILL.md](SKILL.md). Она направляет задачу только к нужным справочным материалам.

## Принципы работы

- Не представлять допущение как подтверждённое нарушение.
- Для каждого критичного или важного замечания приводить конкретное доказательство из продукта.
- Проверять по первоисточникам изменчивые сведения: законы, штрафы, сроки и правоприменительную практику.
- Добавлять обязательный дисклеймер в конце каждого содержательного ответа.

## Содержимое репозитория

- `SKILL.md` — правила аудита, генерации документов и консультаций.
- `references/` — материалы по юрисдикциям и шаблоны отчётов и документов.
- `agents/openai.yaml` — метаданные для интерфейса Codex.

Репозиторий намеренно не публикует кэшированные PDF сторонних организаций. Подробнее — в [references/source-docs/README.md](references/source-docs/README.md).
